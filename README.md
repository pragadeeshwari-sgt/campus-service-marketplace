# Campus Service Marketplace

A campus-based service marketplace where students can offer and request services such as tutoring, graphic design, photography, notes preparation, event assistance, and more.

## Tech Stack

### Frontend
- React.js
- Vite
- Axios
- React Router

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JWT
- bcrypt

## Core Features

- User registration and login
- Role-based access control
- User profiles
- Service listings
- Service search and filtering
- Service request system
- Provider dashboard
- Service status workflow
- Reviews and ratings
- Admin moderation

## Service Workflow

Requested → Accepted → In Progress → Completed → Reviewed
